# Screenshot tooling

The screenshots in `assets/screens` are real captures of Cardfile running on a demo database filled
with **fictional** data (user "Alex Rivera", a launch plan, a Lisbon trip, a sourdough recipe…). The
illustrations inside the cards are generated by `make_images.py`; no third-party artwork is used.

| File | What it does |
|------|--------------|
| `make_images.py` | Draws the flat illustrations used in the cards (Lisbon, sourdough, chart). |
| `showcase.rs` | Cargo example that seeds the demo database (cards, tags, images, history, MCP keys). |
| `dates.py` | Spreads the card and revision timestamps so the list looks lived-in. |
| `win.py` | Windows-only helper that starts Cardfile, clicks, types and captures the window. |
| `publish.py` | Converts the captures to WebP slides, thumbnails and the social card. |

Requirements: Windows, Python 3 with Pillow, and a checkout of `main`.

## Steps

Run from the root of a `main` checkout, with this branch checked out as a worktree in `../Cardfile-site`.
Use any scratch folder for `OUT` (it must not contain a `cardfile.db` yet).

```bash
OUT=/tmp/cardfile-showcase
T=../Cardfile-site/tools/showcase

python $T/make_images.py $OUT/img
cp $T/showcase.rs crates/cardfile-db/examples/showcase.rs
cargo run -q -p cardfile-db --example showcase -- $OUT/data-dark $OUT/img
SHOWCASE_THEME=Paper cargo run -q -p cardfile-db --example showcase -- $OUT/data-light $OUT/img
SHOWCASE_LANG=es SHOWCASE_THEME=Nordic cargo run -q -p cardfile-db --example showcase -- $OUT/data-es $OUT/img
rm crates/cardfile-db/examples/showcase.rs
for d in dark light es; do python $T/dates.py $OUT/data-$d/cardfile.db; done
cargo build --release
```

Then capture (coordinates are relative to the 1600 × 1000 window at 100 % scaling):

```bash
W="python $T/win.py"; S=$OUT/shots; mkdir -p $S
$W start $OUT/data-dark 1600 1000
$W click 380,130 && $W shot $S/editor.png
$W key ctrl+shift+p && $W shot $S/palette.png && $W key esc
$W click 1557,61 && $W shot $S/export.png && $W click 1478,94 && $W shot $S/history.png && $W key esc
$W click 380,647 && $W shot $S/languages.png
$W click 380,795 && $W shot $S/private.png
$W click 196,971 && $W click 225,747 && $W click 1260,201 && $W shot $S/themes.png
$W key esc && $W click 348,437 && $W shot $S/mcp.png && $W click 1311,120
$W click 110,96 && $W type "tram" && $W click 380,130 && $W shot $S/search.png
$W start $OUT/data-light 1600 1000
$W click 380,425 && $W shot $S/travel.png
$W click 380,500 && $W shot $S/recipe.png
$W start $OUT/data-es 1600 1000
$W click 380,130 && $W shot $S/spanish.png
$W close
python $T/publish.py $S ../Cardfile-site/assets .
```

The window must stay visible and unobstructed while `win.py` runs, because captures are taken from
the screen. If the UI layout changes, check each capture and adjust the coordinates above.
